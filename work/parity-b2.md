## Вынужденные преобразования

- Биомы 1.21 хранятся клетками 4×4×4: правило `getBiomeChange` считается один раз на клетку 4×4 (центральная колонка) и пишется на всю высоту чанка. Числовых ID биомов (17.B00–B02) нет.
- Цвет травы: взят цвет при `noise ≥ −0.1` (0x505050 / 0x303030 / 0x6F6752); вариация по шуму (вторые оттенки 0x606060 / 0x404040 / 0x776F59) не воспроизведена. Вода: 0x3F76E4 × множитель 0x505020 = 0x14251D. Туман — `fog_color` = цвет неба, смешение и яркость по времени суток ванильные.
- Дробные правила игры: в `META-INF/accesstransformer.cfg` открыты конструктор `GameRules$Type` и `GameRules$VisitorCaller`. В экране правил мира видны только целые и логические dial-правила.
- Ключи `rbmk*` и `rbmkDials.dialReasimRange` в конфиге остались, но не читаются (значения берутся из правил игры).
- Подписи маркеров — английские литералы оригинала; ключи `chat.reinhardtshbm.pwr.assembly.*` больше не используются.
