# parity g1 — ручная сверка отрисовки GUI (список work/g-gui-part00, 43 пары)

Эталон: HbmMods 1.7.10 @ 936c60c (`work/original`). Слоты не трогались (сверены в e2).
Сверено для каждой пары: drawGuiContainerBackgroundLayer / ForegroundLayer / drawScreen / mouseClicked / keyTyped против renderBg / renderLabels / render / mouseClicked / keyPressed.

Общие решения:
- Баки: `FluidTank.renderTank/renderTankInfo` → `E2TankGui.renderTank/renderTankInfo` (одна полоса с якорем снизу, окраска цветом жидкости, рамка подсказки цвета жидкости). Самодельные `drawFluid` (плитка 16×16, заливка цветом, белая полоска) удалены в правленых экранах.
- `drawElectricityInfo` → `K3GuiText.electricity` («короткое число/короткое числоHE»), вместо `tooltip.reinhardtshbm.energy` с полными числами.
- Области `drawCustomInfoStat`/`checkClick` → `K3GuiText.hover` (x включительно слева, y исключительно сверху, как в эталоне).
- Двойной фон: `AbstractContainerScreen.render` NeoForge 21.1.250 сам вызывает `renderBackground` (проверено по патчу userdev); явный вызов перед `super.render` убран во всех экранах списка, кроме `LegacyBookLoreScreen` (обычный Screen) и `LegacyHeldInventoryScreen` (общий с g2).
- Текстовые поля: фокус следует клику (`GuiTextField.mouseClicked`), сфокусированное поле поглощает все клавиши кроме Esc (`textboxKeyTyped`), чтобы клавиша инвентаря/цифры не срабатывали.
- Призраки ингредиентов (химзавод, химфабрика, прецизионный сборщик): как `GuiInfoContainerProcessor.renderRecipeIcons` — обычный предмет, сверху та же область текстуры слота с альфой 0.5 (z 300), без счётчика и вуали; кандидат меняется раз в 1 с (`extractForCyclingDisplay(20)`).

## Технические адаптации (не меняют содержание)

- ModulePatternMatcher: «Item and meta match» → «Item and components match», «Ore dict key matches» → «Item tag matches» (нет meta/OreDictionary в 1.21) — оставлено, как было в порте.
- Пакеты: AuxButtonPacket/NBTControlPacket заменены существующими payload/`handleInventoryButtonClick` порта.
- Поле эмиттера DFC обновляется из синхронизированного значения, пока не в фокусе (в 1.7.10 значение было в TileEntity на клиенте сразу при открытии).

## Остаток

- Подсказка выбранного рецепта (тигель, химзавод/химфабрика, прецизионный сборщик): эталон рисует `GUIElements.drawHoveringTextRecipe` со значками предметов, порт — текст `describeRecipe` из экранов выбора рецептов (вне списка g1, не менялось).
- LegacyHeldInventoryScreen (свинцовый ящик) — двойной фон оставлен, файл общий с g2 (GUIPlasticBag).
- HeaterScreen общий с g2 (GUIOilburner): правлены только ветки firebox/oven/heatex и `mouseClicked`/`keyPressed`/`renderLabels` (новые общие методы: для oilburner поведение не меняется — полей нет, цвет заголовка серый).
- В игре ничего не проверялось.

## Чек-лист ручной проверки

1. Автокрафтер, эмиттер DFC, силовое поле, электролизёр, химзавод, химфабрика, прецизионный сборщик, камера облучения: наведение на шкалу энергии → `12.5k/100kHE`-подобная строка.
2. Доменная печь: подсказки баков с цветной рамкой; бонусы топлива на пустом слоте топлива.
3. Книга лора: строки переносятся словами по 100 px, `$` — новая строка; стрелки ЛКМ/ПКМ; клавиша инвентаря закрывает.
4. Эмиттер DFC: «Output: …Spk»; ввод «abc» + кнопка — ничего не происходит; ввод «250» → 100; E при вводе не закрывает окно.
5. Приёмник DFC: «Input:» / «Output:» и значение HE = Spk × 5000.
6. Тигель: белый заголовок; слои металла светлее (аддитивный слой 30 %); Shift — объём в mB; иконка рецепта без числа.
7. Дрон-ящик, инжектор DFC, комбинированная печь, пресс ICF, кастомная машина, большая турбина, теплообменник: жидкость в баках текстурой с цветом жидкости, без полос-плиток.
8. Электролизёр: значок питания вверху справа при достатке энергии; металлы текстурой с цветом расплава; звук кнопки переключения.
9. Топка/печь нагрева: бонусы топлива на пустых слотах; две строки `xTU/t`, `ys`; белый заголовок печи нагрева.
10. Теплообменник: поля зелёные без рамки; ввод меняет только своё значение; E в поле не закрывает окно.
11. Силовое поле: подсказки энергии и `HP`; воронка: подсказка режима.
12. Пресс боеприпасов: поиск до 25 символов; повторный клик по рецепту снимает выбор; колесо листает только над окном вне слотов.
13. Химзавод/химфабрика/прецизионный сборщик: призраки ингредиентов полупрозрачные под текстурой слота, меняются раз в секунду; правый светодиод фабрики гаснет без воды/места для пара; у сборщика есть подсказки и правый светодиод.
14. Большая турбина без выходной жидкости: «Error: Invalid fluid!» у значка слева, не у курсора.
15. Все экраны списка: фон затемнения не двойной (сравнить с ванильным сундуком).
