# Parity T3 — взрывоустойчивость блоков (2026-11-17)

Арифметика 1.7.10: `setResistance(r)` → `blockResistance = r*3`; `setHardness(h)` → `blockResistance = max(blockResistance, h*5)`; `getExplosionResistance(e)` → `blockResistance/5`; `BlockStairs(parent)` копирует `blockResistance` родителя. Все взрывы мода (ExplosionNT, ExplosionVNT/BlockAllocator*, ExplosionNukeRayBatched, ExplosionLarge, NukeGeneric) читают `getExplosionResistance` без своих множителей; в порте (LegacyVnt, LegacyMukeExplosion, NukeExplosionManager) тоже напрямую. Значит в 1.21 нужно эффективное значение = blockResistance/5 (при последнем вызове setResistance — 0.6*r). Ваниль: камень 10→6, обсидиан 2000→1200, бедрок 6000000→3600000.
