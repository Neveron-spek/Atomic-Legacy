# Parity T1 — сеть жидкостей (FluidNetMK2)

Эталон: HbmMods 936c60c (`api/hbm/fluidmk2/*`, `com/hbm/uninos/*`, `TilePort`, `blocks/network/*`, `tileentity/network/*`).

| Объект / механика | Оригинал | Было в порте | Стало | Статус |
|---|---|---|---|---|
| Передача за тик | `FluidNetMK2#update`: давления 0..5 раздельно; получатели по приоритетам HIGHEST→LOWEST, доля = спрос/спрос яруса, усечение `(long)`; бюджет яруса уменьшается на накопленный `received[p]`; поставщики списываются по доле, остаток — случайный «козёл отпущения» (≤100 попыток) | асинхронный балансировщик с отставанием на 1 тик, метод наибольших остатков, ротация, давление игнорировалось, приоритет только LOW у бочек; плюс мгновенное проталкивание машинами по курсору | `fluid/HbmFluidNetMK2Transfer` — построчный перенос, синхронно | реализовано, проверено автоматически (T1 algorithm/shares/priorities/pressure) |
| Момент обновления | `ServerTickEvent` START, все миры (`UniNodespace.updateNodespace`) | `LevelTickEvent.Post`, асинхронно | `ServerTickEvent.Pre`, все уровни | реализовано |
| Узлы-машины | `IFluidStandardSender/ReceiverMK2` + `TilePort`: отдающие/принимающие баки, скорость, приоритет, давление | только NeoForge capability (давление 0) | `fluid/HbmFluidNetUser`; без него — capability как приёмник/поставщик давления 0, NORMAL | реализовано для бочек/баков (barrel_*, machine_fluidtank, BAT9000, big ass tank), fluid_pump, flow_control_pump, компрессора, сборочной машины, химзавода, PUREX |
| Проталкивание машинами в трубы | нет (сеть сама забирает) | `fillInto`/`drainFrom` по курсору | для `HbmFluidNetUser` в трубы — отключено (сеть обслуживает) | реализовано; для непереведённых машин проталкивание осталось (расхождение) |
| fluidTracker / счётчик | `fluidTracker = до − после` у поставщиков; counter_valve прибавляет раз в тик | сумма заливки | трекер MK2 (+ проталкивание непереведённых машин) | проверено (counter = 500) |
| Разделение сетей | по типу жидкости (узел на тип), клапаны без узла при meta 0 | по типу, лимит 1024 трубы | по типу, без лимита размера сети | проверено (тип, клапан, ломка трубы) |
| Обновление при установке/ломке | узел создаётся/уничтожается, сеть пересобирается в следующем обновлении | асинхронный решатель | синхронная пересборка компонент | проверено (разрыв/восстановление) |
| debug-информация трубы | Links / Subscribers / Providers / Transfer | + строка Fluid, подсчёт пробами | 4 строки оригинала | реализовано |
| Приоритет machine_fluidtank | наследует TileEntityBarrel: LOW в режиме 1 | NORMAL (проверка L2 закрепляла это) | LOW; проверка L2 исправлена | исправлено |
| tilted (big ass tank) | getDemand/getFluidAvailable = 0 | не учитывалось | учитывается | реализовано |
| fluid_valve / counter_valve | звук `hbm:block.reactorStart` 1.0/0.85, Shift не переключает | `LEVER_CLICK` 0.8 | как в оригинале | реализовано |
| flow_control_pump | BlockDummyable 3×1, вход rot(UP), выход rot(DOWN), буфер 100 (0..10 000), давление 0..5, приоритет, redstone, GUIPump, OBJ с ротором и рельсами, рецепт ` G /SMS/ G ` | отсутствовал | перенесён: блок, BE, GUI (без контейнера), пакет, рендер, предмет, оверлей, рецепт, текстура/OBJ побайтно | реализовано; ожидает ручной проверки |
| fluid_pump (устар., скрыт) | один узел на обе стороны, без GUI и без идентификатора | направленный насос с придуманным GUI | MK2-трансивер на обеих сторонах, GUI/меню удалены | реализовано; расхождение: стороны остаются двумя сетями |
| pipe_anchor_exhaust | дымовые сети SMOKE/SMOKE_LEADED/SMOKE_POISON, текстура `pipe_anchor_exhaust`, рецепт P/P/S (железная труба, полимер) | отсутствовал | перенесён на общий BE якоря (режим exhaust), отдельный тип связи для ключа | реализовано; ожидает ручной проверки |
| Ключ: разные типы якорей | код 1 «Pipes are not the same type» | не проверялось | проверяется | реализовано |
| Мировые блоки/вёдра жидкостей | только mud/acid/toxic/schrabidic/corium/volcanic_lava/rad_lava/sulfuric_acid (+ concrete_liquid); вёдра bucket_mud/acid/toxic/schrabidic_acid/sulfuric_acid | ~95 блоков `fluid_<жидкость>` и ~96 вёдер `<жидкость>_bucket`, mustard_gas, phosgene_gas | лишние удалены; оставлены 7 вёдер (+блоки), на которые опираются теги `c:buckets/diesel|gasoline|fuel` | реализовано |
| network_separator | силовой диод (PowerNetMK2) | отсутствует | не перенесён | не выполнено |
