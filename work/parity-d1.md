# Партия D1 — ИИ и параметры остальных мобов, остатки A2

Эталон: HbmMods 1.7.10 `936c60c` (`entity/mob/*`, `entity/mob/ai/*`, `entity/projectile/EntityBullet`, `EntityBulletBaseNT`, `EntityThrowableNT`, `handler/guncfg/GunNPCFactory`, `BulletConfigFactory`, `handler/BossSpawnHandler`, `config/MobConfig`, `render/entity/projectile/RenderBullet`, `RenderRocket`, `render/util/RenderSparks`, `entity/EntityMappings`).
Статусы: «совпадало», «исправлено», «расхождение (причина)». Автопроверка — `event/ParityD1Diagnostics`, строка `checked_parity_d1_cases` в `run-building-audit/building-audit.txt`. Поведение в игре (движение, цели, снаряды, звуки, рендер) вручную не проверялось.

Общие правила платформы 1.7.10, по которым сверялось: у мобов без `isAIEnabled()` (старый ИИ) `EntityLivingBase.applyEntityAttributes` ставит `movementSpeed` 0.1, а `getAIMoveSpeed()` = 0.1 (ускорение = атрибут × 0.1); цель старого ИИ держится до смерти/креатива; `EntityMob.attackEntity` — раз в 20 т, дистанция < 2.0, пересечение по Y, только при видимости; броня `getTotalArmorValue()` режет урон линейно ×(25−armor)/25; `dropEquipment` — шанс 0.085 на слот при убийстве игроком.

## Оставшиеся расхождения

- Навигация: `PathFinderUtils` (FBI) и пошаговое управление старого ИИ (RAD beast, личинка, призрак: поворот ≤ 30°/т, стрейф при атаке) заменены ванильной навигацией 1.21; правила выбора цели, перестроения пути, дистанции и кулдауны перенесены.

- Siege-мобы и стрельба мобов из оружия (`EntityAIFireGun`) не перенесены.
- У FBI вне верхнего мира стеклянный «шлем» на голове не рисуется (нет слоя блока на голове).
- `BlockDetonatable.onShot` от пули вертолёта не вызывается.
